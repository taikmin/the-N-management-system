# The N Resort Management

> **The N Resort의 매일을, 한 화면과 한 통의 이메일로.**

The N Resort의 대표·관리자·직원이 매일의 업무를 한 곳에서 지시·수행·보고하고, 하루 요약이 매일 대표에게 이메일로 자동 발송되는 웹앱입니다.

> **참고**: 이 문서는 The N Resort 방문 시 발표 자료를 만들기 위한 참조 문서입니다. 개발이 완료되면 실제 구현 내용을 반영하여 최종 갱신됩니다.
> 마지막 업데이트: 2026-09-03 (초안, 계획 기준)

---

## 1. 프로그램 개요

**The N Resort Management**는 호텔·리조트의 일상 업무를 체계적으로 관리하기 위한 통합 웹앱입니다. 관리자가 직원에게 업무를 지시하고, 직원은 수행 결과를 보고하며, 이 모든 활동이 매일 오후 자동으로 대표에게 이메일로 정리되어 발송됩니다.

특히 **자주 현장에 오기 어려운 대표**가, 앱 화면 또는 매일 오는 이메일 한 통만으로도 호텔 전반의 운영 상태를 파악할 수 있도록 설계되었습니다.

---

## 2. 왜 이 프로그램인가

### 현재의 문제
- **대표가 자주 오지 못한다** — 대표가 한 달에 한 번만 리조트에 방문. 나머지 기간 동안 호텔이 어떻게 돌아가는지 즉각적으로 알기 어려움.
- **업무 지시와 보고가 파편화되어 있다** — 카카오톡, 전화, 대면 지시 등으로 분산. 누가 무엇을 했는지 정리되지 않음.
- **반복 업무의 누락** — 매일 해야 하는 정기 업무(로비 점검, 재고 확인 등)를 매일 새로 지시해야 하거나 누락되기 쉬움.
- **보고의 신뢰도** — "했다"는 말만 있고 근거가 부족. 사진 등 증빙 없이 구두 보고.

### 이 프로그램의 해결책
- **한 곳에서 모든 업무를 관리** — 관리자·직원이 같은 앱에서 지시/수행/보고를 처리.
- **매일 이메일 다이제스트** — 대표는 앱을 열지 않아도 하루 요약 이메일 한 통으로 파악.
- **반복 업무 자동화** — 매일/매주 반복 업무는 템플릿으로 등록. 매일 자정에 자동 생성.
- **사진 기반 보고** — 완료 시 사진 첨부로 신뢰도 상승. 미완료/지연 시 사유 필수 입력.

## 3. 주요 사용자

### 3-1. 대표 (CEO)
> "한 달에 한 번만 오는데(자주 방문이 어려운데), 매일 호텔이 어떻게 돌아가는지 알고 싶다"

**주요 사용 방식**:
- **매일 이메일 다이제스트 수신** — 오늘 완료된 업무, 미완료/지연 업무, 부서별 요약을 이메일로 받음
- **필요 시 앱으로 세부 확인** — 대시보드에서 오늘 완료율, 부서별 상태, 지연 업무 요약을 한눈에
- **월 1회 방문 시** — 이번 달의 활동을 앱으로 회고
- **다이제스트 설정** — 대표에게 발송되는 이메일의 수신자 및 발송 시각 설정

### 3-2. 관리자 (Manager)
> "현장에서 직원들에게 업무를 지시하고, 진행 상태를 실시간으로 파악해야 한다"

**주요 사용 방식**:
- **업무 지시** — 앱에서 직원에게 일회성 또는 반복 업무 배정
- **진행 확인** — 지시한 업무의 상태 실시간 확인
- **부서 관리** — 직원 배정, 부서 정보 관리
- **다이제스트 설정** — 대표에게 발송되는 이메일의 수신자 및 발송 시각 설정

### 3-3. 직원 (Staff)
> "오늘 내가 할 일을 확인하고, 완료하면 바로 보고한다"

**주요 사용 방식**:
- **오늘 업무 확인** — 폰으로 오늘 할 일 리스트 확인
- **완료 보고** — 완료 후 짧은 메모 + 사진 첨부로 보고
- **미완료 시 사유 입력** — 지연/미완료 시 사유 필수 입력
- **개인 메모** — 인수인계나 개인 참고사항 기록

## 4. 핵심 기능

### 4-1. 업무 지시 (관리자)
- 제목, 상세 내용, 담당 직원, 부서, 마감일/시간, 우선순위 지정
- **일회성 업무**: 그때그때 지시하는 단발성 업무
- **반복 업무**: 매일/매주/매월 반복 패턴 설정 (예: "매일 오전 9시 로비 점검", "월/수/금 재고 확인")

### 4-2. 업무 수행/보고 (직원)
- 오늘 할 업무 리스트 확인 (내 업무 + 부서 공통)
- **완료 보고**: 
  - 완료 체크
  - 짧은 메모 (선택)
  - 사진 첨부 (선택, 증빙용)
- **미완료/지연 보고**: 
  - 사유 필수 입력
  - 관리자에게 즉시 시각화

### 4-3. 매일 이메일 다이제스트 (대표)
- 매일 지정된 시각(관리자 설정)에 자동 발송
- **내용**:
  - 오늘 완료된 업무 요약
  - 미완료/지연 업무와 사유
  - 부서별 완료율 통계
  - 주요 이슈 하이라이트
- **수신자**: 설정 화면에서 여러 명 관리 가능 (대표, 임원 등)

### 4-4. 반복 업무 자동화
- 관리자가 반복 패턴 설정 (`daily`, `weekly:mon,wed,fri`, `monthly:1,15`)
- **매일 자정에 자동 인스턴스 생성** — 직원 출근 전 오늘 할 일이 이미 준비되어 있음
- 반복 업무도 개별 인스턴스로 관리되어 완료/미완료 추적

### 4-5. 대시보드 (역할별 뷰)
- **대표**: 오늘 완료율, 부서별 상태 카드, 지연 업무 요약, 최근 관리자 활동
- **관리자**: 자기 부서 오늘 상태, 지시한 업무 완료율, 신규 업무 지시 버튼
- **직원**: 오늘 내 업무, 이번 주 반복 업무, 미완료 사유 입력 알림

### 4-6. 캘린더 뷰
- 업무를 캘린더(월/주 뷰)로 확인
- 반복 업무와 일회성 업무 모두 표시
- 지연된 업무는 색상으로 강조

### 4-7. 개인 메모
- 직원별 개인 메모장 (다른 사람과 공유되지 않음)
- 인수인계, 참고사항 등 자유롭게 기록

### 4-8. 부서 관리
- 부서 CRUD (프론트 데스크, 하우스키핑, F&B, 시설/유지보수, 경영지원 등 기본 5개 제공)
- 부서별 팀장 지정
- 직원의 부서 배정

### 4-9. 활동 로그
- 모든 CRUD 활동 자동 기록 (누가 언제 무엇을 생성/수정/삭제/완료)
- 관리자·대표만 조회
- 감사(audit) 및 문제 발생 시 추적

## 5. 사용 시나리오 (하루의 흐름)

### 오전 (직원 출근)
1. **직원**은 폰으로 앱 로그인 → 오늘 할 업무 리스트 확인
2. 밤사이 자동 생성된 **반복 업무**(예: "로비 점검", "객실 상태 확인")가 이미 준비되어 있음
3. **관리자**가 필요 시 신규 일회성 업무 추가 지시

### 오후 (업무 수행 중)
4. **직원**은 업무 완료 시마다 보고 시트에서 완료 체크 + 사진 첨부 + 짧은 메모
5. 특정 업무가 지연되면 **사유 입력 필수** — 관리자가 즉시 인지
6. **관리자**는 대시보드에서 실시간 완료 현황 파악, 필요 시 재배정

### 저녁 (관리자가 설정한 시각, 예: 오후 6시)
7. `send_daily_digest()` 자동 실행 → **대표에게 이메일 발송**
8. **대표**는 스마트폰으로 이메일 열어 오늘 하루 요약 확인
9. 필요 시 앱에 접속해 부서별/직원별 상세 확인

### 자정
10. `generate_recurring_tasks()` 자동 실행 → 다음 날 반복 업무 인스턴스 생성 → 다음 날 아침 직원 출근 시 준비 완료

### 월 1회 (대표 방문 시)
11. 대표가 앱을 열어 이번 달 활동 로그, 부서별 통계, 지연 업무 패턴을 확인
12. 필요한 개선 사항을 관리자와 논의

## 6. 도입 효과

### 대표 관점
- **하루 5분 이메일 확인만으로 호텔 파악** — 매일 앱 열지 않아도 됨
- **월 방문 시 파악 시간 대폭 축소** — 앱 활동 로그로 한 달 흐름 즉시 파악
- **문제의 조기 발견** — 지연 업무 패턴을 통해 구조적 문제 감지 가능

### 관리자 관점
- **업무 지시/추적의 체계화** — 카카오톡·구두 지시의 파편화 해소
- **반복 업무 자동화** — 매일 같은 업무 반복 지시 부담 제거
- **명확한 책임 소재** — 누가 무엇을 어떻게 처리했는지 기록됨

### 직원 관점
- **오늘 할 일이 명확** — 폰에서 리스트만 확인
- **보고의 부담 감소** — 완료 버튼 클릭 + 사진 한 장으로 끝
- **정당한 지연 사유 인정** — 미완료 사유 입력으로 신뢰 관계 유지

### 호텔 조직 전반
- **투명한 운영 문화** — 활동이 기록되고 공유됨
- **데이터 기반 개선** — 부서별 완료율, 지연 패턴 등을 통해 개선 지점 파악

## 7. 기술적 특징

- **웹앱 (Flutter Web)** — PC와 폰에서 모두 동일하게 동작. 앱 설치 불필요, URL만 있으면 접속.
- **반응형 디자인** — 폰에서는 하단 네비게이션, PC에서는 사이드 네비게이션으로 자동 전환.
- **실시간 상태 반영** — Supabase Realtime을 활용해 다른 사용자의 변경사항이 즉시 반영.
- **자동 이메일 발송** — Supabase의 pg_cron + pg_net + Resend API 조합으로 서버 없이 자동화.
- **사진 저장** — Supabase Storage 활용, 업무별 사진 첨부.
- **역할 기반 접근 제어(RLS)** — Postgres Row-Level Security로 데이터베이스 레벨에서 권한 관리. 직원은 본인 업무만 수정 가능 등.
- **한국어 우선** — 한국 호텔 현장에 맞춘 UX와 문구.

**기술 스택**:
- Frontend: Flutter 3.38 (Dart), Material 3, Tiffany Blue `#0ABAB5` 브랜드
- State Management: Riverpod
- Routing: GoRouter
- Backend: Supabase (Postgres, Auth, Realtime, Storage)
- Email: Resend API
- Scheduler: pg_cron + pg_net
- Deploy: Vercel

## 8. 향후 확장 가능성

이 앱은 **호텔 업무·직원 관리에 집중**된 MVP입니다. 다음과 같은 방향으로 확장 가능합니다:

- **게스트/객실/예약 관리** — 별도 모듈로 통합 가능 (현재는 스코프 밖)
- **재고 관리** — F&B, 어메니티 등 재고 추적 모듈
- **매출 대시보드** — 예약/객실 매출 데이터 연동 시 대표용 재무 요약 추가
- **모바일 푸시 알림** — 현재는 이메일 중심이나 FCM 등으로 즉각 알림 추가 가능
- **다국어 지원** — 외국인 직원 대상 영어/중국어 등 추가
- **직원 스케줄/근태 관리** — 근무표, 출퇴근 기록 연동
- **VIP 게스트 응대 프로토콜** — 특별 VIP 방문 시 체크리스트 자동 생성
- **월간 리포트 자동 생성** — 대표 방문 전 지난 한 달 종합 리포트 PDF 자동 생성
