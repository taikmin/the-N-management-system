# Product Vision - R&D Task Manager

## Mission
한국기계연구원(KIMM) 연구자들이 R&D 과제를 효율적으로 관리할 수 있는
통합 플랫폼을 제공한다.

## Problem Statement
현재 R&D 과제 관리의 문제점:
1. **분산된 관리 도구**: 일정은 엑셀, 예산은 별도 시스템, 문서는 폴더 관리
2. **실시간 현황 파악 어려움**: 과제 진행 상황을 한눈에 볼 수 없음
3. **협업 부재**: 연구원 간 업무 공유와 소통이 비효율적
4. **모바일 접근 불가**: 외근/출장 시 과제 현황 확인이 어려움

## Solution
크로스플랫폼 R&D 과제 관리 앱:
- **통합 대시보드**: 모든 과제의 진행률, 예산, 일정을 한눈에
- **업무 관리**: 칸반보드, 간트차트, 체크리스트
- **예산 추적**: 실시간 예산 집행 현황 및 알림
- **문서 관리**: 산출물 업로드, 버전 관리, 검색
- **팀 협업**: 실시간 알림, 코멘트, 멘션

## Target Users
1. **책임연구원(PI)**: 과제 총괄 관리, 예산 승인, 보고서 작성
2. **참여연구원**: 업무 수행, 진행 보고, 산출물 등록
3. **행정담당자**: 예산 집행, 서류 관리
4. **연구실장**: 복수 과제 현황 모니터링

## Key Features (MVP)
### Phase 1 - Core (v0.1)
- [ ] 사용자 인증 (이메일/비밀번호)
- [ ] 과제(프로젝트) CRUD
- [ ] 업무(태스크) CRUD with 칸반보드
- [ ] 기본 대시보드

### Phase 2 - Collaboration (v0.2)
- [ ] 팀원 초대 및 역할 관리
- [ ] 실시간 알림
- [ ] 코멘트 및 멘션
- [ ] 파일 업로드

### Phase 3 - Advanced (v0.3)
- [ ] 예산 관리 모듈
- [ ] 간트차트
- [ ] 보고서 자동 생성
- [ ] 오프라인 모드

### Phase 4 - Enterprise (v1.0)
- [ ] SSO 연동 (KIMM 통합인증)
- [ ] 기관 내 시스템 연동
- [ ] 고급 분석 및 통계
- [ ] 감사 로그

## Success Metrics
- 월간 활성 사용자 (MAU)
- 과제 관리 소요 시간 30% 감소
- 사용자 만족도 (NPS) 40 이상
